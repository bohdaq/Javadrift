= Validation evidence

== Full scanner

Local JDK 23, Java 17 bytecode target. Seven fixture/CLI tests pass. A smoke scan
of the default README scope completed without crashing on these pinned trees:

* commonmark/commonmark-java (b89e72fdb25948c1b9623d64baa29d35d49f8abf): 1 README, 232 public types.
* apache/commons-lang (7fce4c843fcd758da9b3408aaf9435c2471ab218): 1 README, 287 public types.
* apache/commons-io (05f968e913fb43f21ccecb44eba5d523999999f9): 1 README, 300 public types.

A CommonMark nested-type reference exposed a false positive during development;
the index now includes accessible nested types as members, with a regression test.
These smoke scans are not a manually triaged accuracy corpus.

== History scanner

Synthetic Git histories cover five member-reference forms, removed bare types,
comments, wildcard paths, stable baselines and machine output. These deterministic
fixtures test behavior; they do not replace the five real history replays required
by the design's 0.2 release gate. Javadrift's own docs scan has no findings.

== Compiled projects and Maven

Seventeen core/CLI tests pass, including a compiled generated API that overrides
a source-only Lombok skip, JDK inheritance without class initialization, and
numeric Git tag release selection. Maven Invoker verifies a two-module reactor
and a stale-doc build failure; post-build assertions require the expected JD002
finding and compiled output files.

== Gradle and CI outputs

Both Gradle TestKit integrations pass, covering root/subproject compilation,
clean findings, stale members, removed repository assets and unchanged inputs
being up to date. Gradle validatePlugins passes. The Maven reactor still passes
including its two Invoker projects. SARIF fixtures verify stable rule IDs,
locations, escaped URI paths and fingerprints. Composite action shell blocks
pass bash syntax validation; release downloads have not been exercised because
no GitHub release has been published.

== Advanced checks and Java 17

The complete implementation passes 22 core tests, one CLI test, two real Maven
Invoker builds and two Gradle TestKit tests. Both clean Maven verification and
clean Gradle verification/validatePlugins passed on Temurin JDK 17.0.20.1.
The same checks also passed during development on JDK 23.

The standalone source-index benchmark measured 1.424 seconds on JDK 23 and
1.543 seconds on JDK 17 on this Mac: 500 documents, 5,000 classes, 512 MiB max
heap, no findings, including JVM startup. Run python3 scripts/benchmark.py after
building the CLI; use --max-seconds 5 to enforce a local budget. These numbers
are local evidence, not a guarantee for all hardware or repository shapes.

Advanced fixtures cover literal/arity overload mismatch, varargs, unknown
argument types, nested generic constructor expressions, removal deprecation,
three snippet forms, per-block skips, generated bytecode kept in memory,
project snippet classpaths, properties/YAML resources and literal source keys.
Both JD008 and JD009 stay opt-in. The three pinned repository smoke scans
remain clean under the implemented default checks; the 20-repository triaged
accuracy corpus and five real history replays remain outstanding release gates.
