= Natural history review

Every case uses unchanged upstream source and documentation at three pinned
revisions: base, stale head and later documentation fix. Only JD004 runs; no
upstream build or example executes. The manifest records every reviewed stale
and fixed finding, including its document position.

The gate compares complete reviewed finding identities at both revisions, rejects
unreviewed findings and missing reviewed errors, and requires each removed target
to clear. All four natural cases and five reconstructed cases pass locally on
JDK 17. The 21 validation-script tests include six history-gate regressions;
the repository documentation scan reports no findings. The natural report records
six stale findings and one intentionally retained, reviewed true positive.

== CommonMark image attributes

https://github.com/commonmark/commonmark-java/commit/9d192978dc36ad26b23233fdf8570f21947632f2[The source change]
renames the Styles classes to ImageAttributes classes and moves their package.
The base is its parent. At stale head ffdf6ef578e16f02d51426c98d494c2d5305b189,

Both are true positives: the replacement declarations are

under commonmark-ext-image-attributes/src/main/java.
https://github.com/commonmark/commonmark-java/commit/8be430307ef2fe9c84518ab1fd902381217f254b[The documentation fix]
corrects only the extension name. The delimiter-processor reference remains
stale at line 338 and must still be reported. A successful replay therefore
does not imply every finding cleared at the documentation-fix revision.

== Reviewed candidate limitation

KotlinPoet's fdd453a690cf9fa6ef91087505d8eae90e16c66d changes Kotlin factory syntax,
and 0be8e6d68d38f25c0ff0d69b5b285cdca311cc4e later updates the README.
The old ClassName.get syntax is unavailable to Kotlin, but @JvmName("get")
preserves the Java API and the README block is labeled java. The source index
retains JVM aliases and JD004 does not distinguish this language-specific change.
This candidate is excluded from the removed-symbol gate; it is a known coverage
limit, not evidence of a clean Kotlin example. No false positives were observed
in the four included cases, and no analyzer change was needed.
