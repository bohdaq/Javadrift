= Implementation roadmap

Each completed implementation piece below is tested, committed and pushed independently. All six implementation pieces are present in the 0.2.0 CLI preview.

. Foundation: Java 17 Maven reactor, reusable core, packaged JVM CLI, CI and license.
. Full scan: Java source index, Markdown/AsciiDoc extraction, JD001/JD002/JD007,
  conservative matching, YAML configuration, readable output and fixture tests.
. History: Git ref comparison, JD004, rename suggestions, suppressions, baseline,
  JSON/GitHub reporters and replay tests.
. Compiled projects: ASM index (including Kotlin bytecode), Maven aggregator,
  version checks and integration fixtures.
. CI integrations: Gradle task, composite GitHub Action and SARIF reporter.
. Advanced checks: overload/deprecation checks, opt-in snippet compilation and
  configuration property checks, with explicit limits.

== Release gates

Implementation does not establish the design's release acceptance targets.
The 20-repository corpus is pinned and manually triaged; five real refactorings
are replayed with parent documentation restored. The local 500-document/5,000-class
benchmark meets the five-second budget. See link:validation.adoc[validation evidence]
for scope and limitations.

Maven Central/Gradle Portal publishing and an external CI adopter remain pending.
Broader documentation coverage, more positive findings and naturally stale upstream
history are needed before claiming broad accuracy. Kotlin source/history declaration indexing is implemented; full compiler type
resolution and Kotlin snippet compilation remain future work.

== Decisions

* Apache-2.0 license.
* Markdown and AsciiDoc docs.
* JVM CLI only; no native binary.
* Kotlin compiled classes use the same ASM index as Java. Kotlin declaration
  parsing and Git history use the embedded syntax parser; full type resolution
  is outside the current implementation.
* Diff matching stays inside code formatting to avoid noisy prose matches.
